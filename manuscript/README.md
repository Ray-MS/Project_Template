## 交叉引用格式

引用图、算法和表格时，标签前缀后用不换行空格 `~` 连接 `\ref`，避免序号与标签被换行分开。

- 图：`Fig.~\ref{fig:...}`
- 算法：`Alg.~\ref{alg:...}`
- 表：`Table~\ref{tab:...}`
